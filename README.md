# تواصل — موقع تواصل اجتماعي بـ Python Flet

موقع تواصل اجتماعي مبني بالكامل بلغة **Python** باستخدام مكتبة **Flet** وقاعدة بيانات **SQLite**، بواجهة عربية من اليمين إلى اليسار.

![الصفحة الرئيسية](docs/screenshot-feed.png)

## المميزات

- إنشاء حساب وتسجيل دخول (كلمات المرور مشفّرة بـ PBKDF2-SHA256 مع salt)
- نشر المنشورات وحذف منشوراتك
- الإعجاب بالمنشورات وإلغاء الإعجاب ❤️
- التعليق على المنشورات 💬
- متابعة المستخدمين وإلغاء المتابعة
- الصفحة الرئيسية تعرض منشوراتك ومنشورات من تتابعهم
- صفحة استكشاف فيها كل المنشورات والبحث عن مستخدمين
- ملف شخصي (عدد المنشورات والمتابِعين ومن يتابعهم) مع تعديل الاسم والنبذة
- وضع ليلي 🌙 وخط عربي (Cairo) مضمّن

![الملف الشخصي](docs/screenshot-profile.png)

## التشغيل

```bash
pip install -r requirements.txt
python main.py
```

سيفتح الموقع تلقائياً في المتصفح على: http://localhost:8550

- لتغيير المنفذ: `PORT=9000 python main.py`
- لتغيير مكان قاعدة البيانات: `SOCIAL_DB=/path/to/social.db python main.py`
  (الافتراضي `social.db` بجانب `main.py`، ويتم إنشاؤها تلقائياً)

## بنية المشروع

| الملف | الوصف |
|------|------|
| `main.py` | واجهة المستخدم (Flet): تسجيل الدخول، الرئيسية، الاستكشاف، الملف الشخصي، التعليقات |
| `database.py` | طبقة قاعدة البيانات (SQLite): المستخدمون، المنشورات، الإعجابات، التعليقات، المتابعات |
| `assets/fonts/` | خط Cairo العربي (رخصة OFL) |
| `tests/` | اختبارات قاعدة البيانات |

### جداول قاعدة البيانات

- `users` — المستخدمون
- `posts` — المنشورات
- `likes` — الإعجابات
- `comments` — التعليقات
- `follows` — المتابعات

## الاختبارات

```bash
pip install pytest
python -m pytest tests
```
